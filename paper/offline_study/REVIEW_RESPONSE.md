# Disposition of the 9 November review

| Finding | Treatment in this paper |
| --- | --- |
| Unrun LLM study presented as completed | New title, abstract, methods, results and conclusion concern only scripted offline experiments. The model study is future work. |
| Main text, design and code describe different environments | The paper specifies the implemented 720-second, 100-lot model. No calibrated background population or two-hour result is claimed. |
| 180-second window tuned on the reported evasion sample | Recall is labeled tuning performance. A 320-episode legitimate-maker cadence grid is reported in the main results, including 34/40 alerts at a 180-second cadence. |
| Zero residual routes not calculated by the published endpoint | Add 40 matched gated unresponsive runs. Compute wealth differences at the same gate and seed; do not equate any rejection with complete prevention. Preserve historical fields. |
| Shared detector windows described as separate | Explicitly document that spoof, layer and aggregate patterns share the age window. Do not silently alter historical algorithms. |
| Same-side display helper sums both sides | Add and test `max_displayed_per_side`; use it in the new evidence. Historical measurements remain historical. |
| Legacy-versus-aggregate cost obscures throttle interaction | Report the throttle-isolation comparison and its session-length dependence. |
| Intent inferred from missing explanations | No intent findings. Future explanations require an unavailable category distinct from benign evidence. |
| Unsupported preregistration and pre-run Git commitment | No preregistration claim. Generator, draws and results first appear together in the available history. |
| Historical regeneration follows mutable root config | New study reads frozen cohort configs. Document the limitation of historical regeneration; preserve the working historical replay procedures. |
| Template instructions and unresolved author citations | New prose, actual tables/figures, a short verified primary-source bibliography, no placeholder results or editorial instructions. |
| Missing manuscript source | Include the paper builder, complete structured text, bibliography, figures, and hash manifest. |

The new cadence grid follows the review diagnostic and reuses the negative-control
seeds. Neither it nor the corrected endpoint is described as confirmatory or
independent external validation. Zero observed response advantage remains limited
to the model and sampled parameter family.
